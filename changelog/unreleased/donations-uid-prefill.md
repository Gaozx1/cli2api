### English

- A contribution link can pin the recipient: `…/donations?uid=123` opens the page with the New API user id already filled in and locked, so a contributor cannot accidentally credit someone else, and the query string is removed from the address bar as soon as the link is opened.
- The accounts page now shows which New API user contributed an account and what was contributed (provider, region, format), so a contributed account is distinguishable from an operator-created one.

### 中文

- 贡献链接可以指定收款人：`…/donations?uid=123` 打开后 New API 用户 ID 已自动填好并锁定，贡献者不会误把额度发给别人；链接打开后地址栏上的查询参数会立即消失。
- 账号页现在会显示账号是由哪个 New API 用户贡献的，以及贡献的内容（平台、区域、格式），便于区分贡献账号与自建账号。
