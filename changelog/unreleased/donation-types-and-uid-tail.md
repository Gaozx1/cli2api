### English

- The contribution page can be limited to chosen account types, from System settings. The rule is enforced on the server, so an unchecked type cannot be contributed by posting to the API directly either. Leaving every type ticked means "no restriction", which is the previous behaviour.
- The overview now reports how many accounts arrived through the contribution page, and how many distinct New API users sent them.
- A contribution link keeps its `?uid=` in the address bar instead of having it stripped, so a shared or bookmarked link still works. The recipient stays fixed and uneditable, as before.
- The contribution page no longer states the reward amount. It says that accepted accounts earn site credit, without naming a figure.

### 中文

- 贡献页面可以限定只接受指定的账号类型（在「系统设置」里勾选）。该规则在服务端生效，因此未勾选的类型即便直接调用接口也无法贡献。全部勾选表示"不限制"，与之前的行为一致。
- 概览页现在显示有多少账号来自贡献页面，以及有多少位不同的 New API 用户提交。
- 贡献链接不再剥离地址栏里的 `?uid=`，分享或收藏的链接仍然有效。接收人依旧固定、不可修改。
- 贡献页面不再显示奖励金额，只说明通过的账号会发放站点额度，不写具体数字。
